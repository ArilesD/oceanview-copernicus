À propos d'OcéanView

Plateforme d'analyse et de visualisation des données océanographiques.

Le Projet OcéanView

OcéanView est une application océanographique développée dans le cadre de la SAE 3.01. Elle agrège et visualise des indicateurs environnementaux pour analyser la santé des océans en Europe.

L'application offre un tableau de bord complet permettant de suivre :

  • Température (SST) : Température de surface de la mer.
  • Salinité (SSS) : Salinité de surface.
  • Chlorophylle-a (Chl-a) : Concentration en Chlorophylle-a.

Source des Données

Les données proviennent du programme européen Copernicus Marine Service pour récupérer :

  • Les archives.
  • Les données en temps réel.

Architecture & Stack Technique

Backend & Data :
Python Flask (MVC) MySQL Pandas / Xarray Copernicus API
Frontend & Visualisation :
JavaScript Leaflet.js (Carto) Plotly.js (Graphes) HTML / CSS
